# Задача бэкенд #1: `POST /api/validate` (разбор спеки без генерации)

**Объём:** ~1–2 часа. **Файлы:** `app/api.rb`, `test/test_api.rb`.
**Зависимостей от других нет** — фасад `Paybridge.parse_only` уже готов в `lib/paybridge.rb`.

## Что делает эндпоинт

Принимает `provider_api.yaml`, **разбирает** его и возвращает распознанную модель
(методы, авторизация, маппинг статусов/ошибок, webhook, предупреждения) — **без генерации
файлов**. Нужен, чтобы показать «что понял парсер» до нажатия «Сгенерировать».

## Контракт

**Запрос:** `POST /api/validate`, `multipart/form-data`
- `spec` — файл `.yaml`/`.yml` (обязателен)
- `provider` — строка `^[a-z][a-z0-9_]{1,32}$` (обязателен)

**Ответ `200`** (ровно то, что вернул `Paybridge.parse_only`):
```json
{
  "provider": "novapay",
  "title": "NovaPay Payout API",
  "version": "1.0.0",
  "base_url": "https://api.sandbox.novapay.example/v1",
  "endpoints": [ { "method": "POST", "path": "/payouts", "role": "create" } ],
  "auth": { "type": "apiKey", "header": "X-API-Key", "credentials_field": "api_key" },
  "idempotency_header": "Idempotency-Key",
  "status_map": { "pending": "in_progress", "completed": "approved" },
  "error_map": { "402": "insufficient_balance" },
  "webhook": { "path": "/webhooks/payout", "events": ["payout.completed"], "signature_header": "X-NovaPay-Signature", "signature_alg": "SHA256" },
  "warnings": []
}
```

**Ошибки** (как в `POST /api/integrations`):
- нет файла / кривой `provider` → `400`
- файл > 1 МБ → `413`
- битый YAML / не OpenAPI (`Paybridge::GenerationError`) → `422` c `{ "error": { "code": "validation_failed", "message": "..." } }`

**Важно:** файлы НЕ генерируются и в `storage/` ничего не сохраняется. Это dry-run.

## Что именно вписать в `app/api.rb`

Рядом с `post '/api/integrations'` добавить:

```ruby
post '/api/validate' do
  file     = params[:spec]
  provider = params[:provider].to_s

  error!('missing_spec', 'Файл spec обязателен', 400) unless file.is_a?(Hash) && file[:tempfile]
  error!('invalid_provider', 'provider должен соответствовать ^[a-z][a-z0-9_]{1,32}$', 400) unless provider.match?(PROVIDER_RE)
  error!('invalid_type', 'Ожидается файл .yaml или .yml', 400) unless file[:filename].to_s.match?(/\.ya?ml\z/i)

  content = file[:tempfile].read
  error!('too_large', 'Файл больше 1 МБ', 413) if content.bytesize > MAX_SPEC_BYTES

  spec_path = store.tmp_spec(content)
  begin
    model = Paybridge.parse_only(spec_path: spec_path, provider: provider)
  rescue Paybridge::GenerationError => e
    error!('validation_failed', e.message, 422)
  ensure
    File.delete(spec_path) if spec_path && File.exist?(spec_path)
  end

  json_response(model)
end
```

> Заметь: блок валидации входа тут дублирует `POST /api/integrations`. Если хочешь —
> вынеси в helper `read_spec_param!` и вызови в обоих местах. Не обязательно для сдачи.

## Тест — добавить в `test/test_api.rb`

```ruby
def test_validate_returns_model_without_generating
  post '/api/validate', spec: spec_upload, provider: 'novapay'
  assert_equal 200, last_response.status
  body = JSON.parse(last_response.body)
  assert_equal 'X-API-Key', body.dig('auth', 'header')
  assert_equal 'in_progress', body.dig('status_map', 'pending')
  refute_empty body['endpoints']
end

def test_validate_bad_yaml_422
  file = Tempfile.new(['bad', '.yaml'])
  file.write("openapi: [unclosed\n")
  file.rewind
  post '/api/validate',
       spec: Rack::Test::UploadedFile.new(file.path, 'application/x-yaml'),
       provider: 'novapay'
  assert_equal 422, last_response.status
ensure
  file.close!
end
```

## Критерии приёмки (Definition of Done)

- [ ] `POST /api/validate` возвращает `200` с моделью (endpoints, auth, status_map, error_map, webhook, warnings).
- [ ] В `storage/` при этом ничего не создаётся (dry-run).
- [ ] Битый YAML → `422`; нет файла / кривой `provider` → `400`; > 1 МБ → `413`.
- [ ] Оба новых теста зелёные: `ruby -Ilib -Itest test/test_api.rb`.
