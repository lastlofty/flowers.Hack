# Аудит безопасности — novapay

Автоматический разбор платёжных рисков интеграции. Провенанс: PayBridge
1.0.0, spec sha256 `415f50ee36fb331dfab49ceed0e8ed3b0ebe16053d7e00dbabd32282f4396551`.

**Вердикт: ⚠️ Требует внимания**

| Проверка | Статус | Комментарий |
|---|:--:|---|
| Подпись webhook | ✅ | HMAC-SHA256 по `X-NovaPay-Signature` (hex); проверяется по сырому телу |
| TLS (HTTPS) | ✅ | BASE_URL по https |
| Авторизация | ✅ | apiKey через `X-API-Key` |
| Идемпотентность | ✅ | заголовок `Idempotency-Key` на создании |
| Сумма | ✅ | единица: minor (копейки/центы); поле `amount` |
| Диагностика | ⚠️ | 4 предупреждений, 1 info |
